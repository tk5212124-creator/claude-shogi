# 将棋アプリ 仕様書

ブラウザだけで動く多変種ボードゲームアプリ。ファイルは **`shogi.html` 1枚だけ**（ビルド不要・外部依存なし）。

公開URL: https://tk5212124-creator.github.io/claude-shogi/

---

## 1. 全体像

| 項目 | 内容 |
|---|---|
| 構成 | `shogi.html` 単体（HTML + CSS + バニラJS） |
| 対応ゲーム | 本将棋・平安将棋・小将棋・5五将棋・中将棋・大将棋・摩訶大大将棋・大局将棋・チェス・シャンチー・チャンギ・どうぶつしょうぎ・オセロ・囲碁・はさみ将棋 |
| 駒の種類 | 約420種（大局将棋 209種＋成92種、各変種の駒を含む） |
| 対局形式 | 人間 対 人間／人間 対 CPU／CPU 対 CPU |
| 公開 | GitHub Pages（`main` へ push すると自動デプロイ） |

### 設計上の絶対ルール

**人間の指し手と CPU の指し手で機構を変えない。**
着手は必ず `applyMoveSilent(side, move)` の1本を通り、合法判定は必ず `isLegalMove(move, side)` を通る。
演出の有無・描画の間引きは「音・演出トグル」と「速度設定」だけから決まり、指し手の主体では分岐しない
（`fxEnabled()` / `renderThrottled()`）。

## 2. 盤の構造 — 2つのレイヤー

盤は **マスの層** と **交点の層** の2枚でできている。

```
board[r][c]      … マスの中に置かれた駒     （NR × NC）
ptsBoard[r][c]   … 線の交点に置かれた駒     （NR+1 × NC+1）
```

**交点 (r,c) は マス (r,c) の左上の角**。つまりマスの中心と交点は必ず別の点になる。
9×9 の盤なら交点は 10×10 個ある（外周の線にも駒が乗る）。

### 2層のあいだのルール

| 状況 | 挙動 |
|---|---|
| 取り合い | **できない**（別の点にいるので重ならない） |
| 縦横の進路 | **塞がない**（通り道に相手レイヤーの点が来ない） |
| 斜めの進路 | **塞ぐ**（通り道にちょうど相手レイヤーの点が来る） |
| 九宮の交差マス(×) | 斜め線がマスの中心で交わる＝**2層の共有点**。両方が置け、そこでは取り合える |
| 碁石の囲み取り | マス・交点に**関係なく**取れる |
| 斜めに飛び越えて動く駒 | 跳び越える途中の**交点の駒も取れる**（馬・象・桂馬型） |

### 層をまたぐ移動

マスの中心と交点は「斜め半歩」ずれているので、**斜めに動ける駒だけ**が層を行き来できる
（歩のように斜めへ進めない駒は行き来できない）。

| 置き方 | 層をまたげる場所 |
|---|---|
| `free` | 交差宮マス(×)に居るときだけ |
| `freeMove` | いつでも |
| その他 | またげない |

角行のように斜めへ走る駒は、その斜め方向にある**交点にもマスにも**自由に進める。

斜めの通り道の座標:

```
マス(r,c) から斜め(dr,dc) へ  →  通る交点は (r + max(0,dr), c + max(0,dc))
交点(r,c) から斜め(dr,dc) へ  →  通るマスは (r + min(0,dr), c + min(0,dc))
```

### 駒の置き方（盤の設定「駒の置き方」）

| 設定 | 交点に置かれる駒 | マスに置かれる駒 |
|---|---|---|
| `auto`（既定） | 囲碁・シャンチー・チャンギの駒 | それ以外 |
| `cell` | なし（交点レイヤーを使わない） | すべて |
| `point` | すべて | なし |
| `free` | 自由（編集で選んだ側に置ける） | 自由 |
| `freeMove` | 自由。さらに**常時どちらの層へも進める** | 自由 |

編集モードでは「置く場所」（マスの中／線の交点）を明示的に選ぶ。`auto` のときは種類に合わない側には置けない。

## 3. 九宮（宮マス）

九宮は**マスの斜め線属性**として表現する。各マスは `'l'`(＼) / `'r'`(／) / `'x'`(交差) / `null` のいずれかを持つ（`cellDiag[r][c]`）。
編集メニューの「宮マス変更」で1マスずつ、複数選択バーの「宮マス変更」でまとめて設定できる。

### 宮の判定（**盤の位置では判定しない**）

| 対象 | 宮かどうかの判定 |
|---|---|
| マス (r,c) | そのマスが斜め線を持つ、または交差マス(×)の縦横1マス隣 |
| 交点 (R,C) | その交点を角に持つ4マスのどれかが斜め線を持つ |

宮が盤のどこにあっても同じように動ける。

### 宮から出られない駒（帥・將・仕・士・漢・楚）

九宮のチェックの有無に関係なく、常に宮の外へは出られない（宮が無ければ動けない）。
ルール設定の「九宮の駒が宮マスの外にも出られるようにする」で解除できる。

**交点に居るとき**

- 帥・將 … 宮の点どうしを縦横1つ
- 仕・士 … その交点から**実際に伸びている斜め線の向き**にだけ
- 漢・楚 … 縦横＋線に沿った斜め

**マスの中に居るとき**

- 仕・士 … そのマスに引かれた斜め線の向きにだけ
- 帥・漢 … 宮のマスの中、または交差宮マスの縦横1マス隣まで

## 4. ルール設定

### 共通

| 設定 | 既定 | 内容 |
|---|---|---|
| 持ち駒を使う | ON | 取った駒を打てる |
| 取った駒は成ったまま | OFF | 成駒のまま持ち駒にする |
| 二歩を禁止 | ON | |
| 千日手の扱い | 千日手を避ける | 避ける／同一局面4回で引き分け／シャンチー式／制限なし |
| パス（着手放棄） | OFF | 盤下に「⏭ パス」。CPU も同じ手として使う |
| 格なしの駒を一般駒として扱う | ON | 範囲攻撃の対象になる |
| ランダム置換・ランダム成りの候補に特殊駒を含める | ON | 囲碁石・オセロ駒・はさみ駒。他は常に候補 |
| 成り条件をもう一度満たすと更に成れる | OFF | 満たした条件の数だけ連続で成る |
| 成り先のない駒はランダムな駒に変化 | OFF | royal は royal へ |
| 取り切るまで戦う | OFF | 王の有無に関係なく全滅で決着 |

### 成る条件（3つとも外すと成りが無くなる）

敵陣に入ったら／敵陣の一番奥に着いたら／敵駒を取ったら

### 勝敗の一般則

**盤上から味方の royal 駒（王・玉・帥・漢・ライオンなど）が居なくなった側の負け。**
取られた・オセロで裏返された・碁石に囲まれた・焼かれた…どの理由でも同じ扱いで、
着手のたびに両者を確認する。持ち駒の royal は数えない（盤上だけを見る）。
「相手の駒を全て取る（取り切る）まで戦う」ルールのときだけ別で、王の有無では決着しない。

### 引き分け（持将棋）

どこにも動けなくなったら（既定ON）／双方の王が敵陣に入ったら（既定OFF）。点数計算は24点法。

### シャンチー

- 王不見王（帥と将を同じ筋で相対させる手は指せない）
- 九宮の駒が宮マスの外にも出られるようにする

### チャンギ

- ビッチャングン（漢・楚が相対したら、相手は解消する手しか指せない。解消できなければ引き分け）
- 馬・象の並び（標準／馬が内側／左だけ入替／右だけ入替）

チャンギのプリセット適用時は **持ち駒OFF・ビッチャングンON・パス可** が自動で入る。

## 5. 変種ごとの実装メモ

### シャンチー

炮は取るときだけ砲台を1枚跳び越える。馬・象は**駒を飛び越えられない**（蹩馬腿・塞象眼）。
兵・卒は河（敵陣＝既定5段）を越えると `+XP` に成り、横にも動けるようになる（赤文字表示）。

### チャンギ

包は**必ず**1枚跳び越える／包を台にできない／包を包で取れない。
象は「縦横1＋斜め2」。兵・卒は最初から横にも動け、成りは無い。
宮の中では王・士・車・包・兵が斜め線に沿って動ける。初手で包が動けないのは配置から自然に決まる。

### シャンチー・チャンギの初期配置

置き方で盤の大きさが変わる。

| 置き方 | 盤 | 配置先 |
|---|---|---|
| 交点に置く | 9行 × 8列 | 9筋 × 10段の**交点**（32枚） |
| すべてマスの中 | 10行 × 9列 | **マス**（32枚） |

### 囲碁・オセロ・はさみ将棋

プリセット適用で「取り切るまで戦う」が自動ON。囲碁・オセロは打ち込み専用なので持ち駒が必ずONになる。
はさみ将棋は打ち込みなし（持ち駒OFF）。

### どうぶつしょうぎ

ライオンが最奥段に到達し取り返されなければ「トライ」で勝ち。

## 6. 編集モード

「編集ツール」を開くと編集モード。盤のマス／交点をタップして駒を配置・変更する。

### 操作

| 操作 | 動き |
|---|---|
| 盤を長押し（非編集時） | 編集モードに入る |
| 駒・マスを長押し（編集時） | 編集メニュー（説明／変更／置く側の切替／複数選択／宮マス変更） |
| 駒をドラッグ | 同じ側の中で移動 |
| 駒を持ち駒欄へドラッグ | その側の持ち駒に移す |
| 駒をゴミ箱へドラッグ | 削除 |
| 軽くタップ（編集時） | 編集モード解除（複数選択中はトグル） |

### 編集モード中の画面

盤の直下に「置く場所」→ 編集ツールのボタン群 → 盤の設定 の順で並ぶ（編集を終えると元の位置に戻る）。

- 置く場所（マスの中／線の交点）
- 自陣の配置を敵にコピー／敵陣の配置を自陣にコピー（2層とも点対称に写す）
- ランダム置換（強さ近い／同じ格／完全）— 2層とも、それぞれ置ける駒だけを候補にする
- 記憶した配置に戻す／盤を空にする
- 盤の設定（プリセット／行×列／敵陣／駒の置き方／九宮をつくる）

盤の大きさを変えても駒・持ち駒は消えない（はみ出す分だけ落ちる）。空にするのは専用ボタン。

### 駒一覧（この駒を変更）

「置く場所」に合う駒だけが出る。各セクションの「プリセット配置」で、選んだマスを左上として自陣のみを配置できる
（交点駒のプリセットはマスの駒を、マス駒のプリセットは交点の駒を消さない）。

## 7. 保存・読み込み

| ボタン | 内容 |
|---|---|
| ルール・初期配置をコピー | 盤・交点・持ち駒・ルール・斜め線（**指し手は含まない**） |
| 棋譜（ルール・初期配置含む）をコピー | 上記＋指し手＋起点＋読みやすいテキスト |

貼り付け欄に貼って「読み込み」すると復元する。

- **ルール・初期配置**を貼る → そのルール・その配置から始められる
- **棋譜**を貼る → その対局の続きから再開できる（リプレイも見られる）

デバッグ情報まるごと貼っても、中の JSON 部分を自動で取り出して読み込む。

## 8. CPU

αβ探索。評価は駒の価値＋前進ボーナス＋敵玉への接近ボーナス。
深さは速度設定から決まり、盤が大きいほど浅くする（18路以上は深さ1、13路以上は深さ2）。
着手は必ず人間と同じ `isLegalMove` を通す。

## 9. 演出

「音・演出：ON」かつ超高速以外のときだけ動く。

- **駒を取る** … 斬線3本（会心5本＋金の一閃）／ヒット閃光／衝撃波リング／木片／粒子／ダメージ数値／盤の揺れ＋ヒットストップ。会心は画面ごと振動＋2度焚きフラッシュ＋集中線
- **成る** … 画面全体の金フラッシュ＋集中線＋衝撃波＋振動、放射光、光柱、金のリング3重、輝きの粒
- **移動** … 残像と着地の土煙
- **王手** … 赤いビネットと集中線
- **オセロ** … 1枚ずつめくれてリングが弾け、4枚以上で「○枚返し！」
- **勝敗** … 画面フラッシュ＋振動、紙吹雪120枚、勝利は星も舞う

効果音は Web Audio で合成（外部ファイルなし）。BGM も同様。

## 10. 主要な関数

| 関数 | 役割 |
|---|---|
| `moves(b,r,c)` | レイヤー `b` 上の (r,c) の駒の着手先。`LR(b)`/`LC(b)` で層ごとの広さを見る |
| `genMoves(b,p,cy,ce)` | 2層＋持ち駒＋パスを合わせた着手一覧。交点の手は `pt:true` |
| `isLegalMove(m,p,b)` | 人間・CPU共通の合法判定（千日手回避・王不見王・ビッチャングンを含む） |
| `simulate(b,m,p,cy,ce)` | 読み用に2層コピーして着手 |
| `applyMoveSilent(side,m)` | 実盤への唯一の着手経路 |
| `ptDiagDirs(R,C)` / `isPalacePoint(R,C)` | 交点から見た宮の判定 |
| `isPalaceCell(r,c)` | マスから見た宮の判定 |
| `crossJumpPoints(...)` | 斜めに飛び越える駒が通る相手レイヤーの点 |
| `stateJSON()` / `loadState(text)` | 保存・復元 |
